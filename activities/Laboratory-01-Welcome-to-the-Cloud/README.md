# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the basic environment and tools used in cloud computing. The activity focused on using a Linux environment through KillerCoda, gathering system information, organizing files and directories, documenting technical work using Markdown, and creating a GitHub portfolio.

## Objectives

- Access and use a cloud-based Linux environment.
- Navigate the Linux file system.
- Gather basic Linux system information.
- Create and organize files and directories.
- Document technical work using Markdown.
- Use GitHub to maintain a cloud computing portfolio.

## Activities Performed

1. Launched an Ubuntu 24.04 environment using KillerCoda.
2. Created and logged into a Linux environment.
3. Recorded the username, working directory, and hostname.
4. Gathered Linux distribution, kernel, CPU, memory, and disk information.
5. Created and organized the required directory structure.
6. Created Markdown documentation files.
7. Prepared the laboratory files and screenshots.
8. Organized the laboratory output in the GitHub portfolio.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `ls` – lists files and directories.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `cat` – displays file contents.
- `uname` – displays system and kernel information.
- `lscpu` – displays CPU information.
- `free` – displays memory information.
- `df` – displays disk space information.
- `git status` – checks the Git repository status.
- `git add` – stages files for commit.
- `git commit` – records changes in Git.
- `git push` – uploads commits to GitHub.

## Skills Learned

Through this activity, I learned how to work with a cloud-based Linux environment, navigate directories, create and manage files, gather basic system information, document technical work using Markdown, and organize laboratory outputs in GitHub.
