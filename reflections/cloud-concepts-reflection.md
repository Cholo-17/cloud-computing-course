**1. Cloud Services I Use: List at least 3 cloud services or applications you use regularly (e.g. Google Drive, Netflix, Messenger, Canva, GCash).**

*I use several cloud services for school, communication, entertainment, and social media. Examples include Google Drive, Facebook Messenger, Netflix, Instagram, and TikTok.*

**2. Identify the Models: For each service you listed, identify its service model (IaaS / PaaS / SaaS) and deployment model (Public / Private / Hybrid / Community). Briefly explain why you chose that classification.**

*The cloud services that I use every day are Google Drive, Facebook Messenger, Netflix, Instagram, and TikTok. Google Drive is classified as Software as a Service (SaaS) because it allows me to create, store, edit, and share my files online without having to manage the underlying hardware or software. It uses the **Public Cloud** deployment model because I can access it through the internet from any device with my account. Facebook Messenger is also an example of **SaaS** because it provides messaging, voice calls, and video calls through an online application, while all the infrastructure is managed by the service provider. It uses the **Public Cloud** model since it is available to anyone with an internet connection. Netflix is classified as **SaaS** because it delivers movies and television shows through an online streaming platform without requiring me to install or maintain any servers. It also uses the **Public Cloud** deployment model because I can stream content over the internet from different devices. Instagram is another example of **SaaS** because it allows me to share photos and videos, send messages, and interact with other users through its online platform. It follows the **Public Cloud** deployment model because its services are accessible to users around the world through the internet. Lastly, TikTok is classified as **SaaS** because it provides video-sharing and entertainment services through its mobile application, with all technical resources managed by the provider. It also uses the **Public Cloud** deployment model because it is hosted online and available to the general public through the internet.*

**3. Git & GitHub for Cloud Projects: Explain why version control is critical when working with cloud infrastructure. How does GitHub help teams collaborate, track changes, and prevent errors when managing cloud resources?**

*Version control is important because it keeps a history of changes made to files, settings, and cloud resources. It shows who made each change and when it was made. If an error occurs, team members can review the changes, identify the problem, and restore an earlier working version. GitHub provides a shared platform where team members can store, manage, and collaborate on project files. Team members can work on separate branches without changing the main project directly. They can also use pull requests to review and discuss changes before adding them to the main branch. This reduces errors and helps prevent people from accidentally overwriting important work. Cloud services make everyday activities such as communication, schoolwork, entertainment, and social media easier and more accessible. Version control tools such as Git and GitHub help teams manage cloud-based projects in a safe, organized, and collaborative way.*
