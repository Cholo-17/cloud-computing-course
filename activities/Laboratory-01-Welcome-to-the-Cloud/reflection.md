# Reflection

This laboratory activity helped me understand the basic environment used in cloud computing. I learned how to access an Ubuntu Linux environment through KillerCoda and how to navigate the Linux file system using different commands.

I also learned how to gather basic system information such as the Linux distribution, kernel version, CPU information, memory, and disk space. Creating and organizing the required files helped me understand the importance of proper documentation.

Another important part of the activity was learning how Git and GitHub can be used to organize and maintain my laboratory outputs. Overall, this activity gave me a better understanding of the basic Linux and Git skills needed for cloud computing.
