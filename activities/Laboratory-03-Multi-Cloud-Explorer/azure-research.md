# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, databases, networking, security, artificial intelligence, and enterprise applications.

## Global Infrastructure

Azure operates a worldwide infrastructure consisting of regions and availability zones. Organizations can deploy applications close to their users and improve availability.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services

1. Azure Virtual Machines – Provides virtual servers.
2. Azure Blob Storage – Provides object storage.
3. Azure SQL Database – Provides managed SQL databases.
4. Azure Virtual Network – Provides private networking.

## Three Advantages

1. Azure has strong integration with Microsoft products.
2. Azure provides extensive enterprise services.
3. Azure supports hybrid cloud environments.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows Server workloads, Microsoft 365 integration, databases, web applications, artificial intelligence, and hybrid cloud infrastructure.
