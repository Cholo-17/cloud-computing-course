# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services for computing, storage, databases, networking, security, analytics, and artificial intelligence.

## Global Infrastructure

AWS operates a large global infrastructure made up of Regions and Availability Zones. This infrastructure allows organizations to deploy applications in different geographical locations and improve availability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources.

## Four Core Services

1. Amazon EC2 – Provides virtual servers for running applications.
2. Amazon S3 – Provides object storage for files and data.
3. Amazon RDS – Provides managed relational databases.
4. Amazon VPC – Provides networking for AWS resources.

## Three Advantages

1. AWS provides a very large selection of cloud services.
2. AWS has a global infrastructure for deploying applications worldwide.
3. AWS supports organizations ranging from startups to large enterprises.

## Typical Enterprise Use Cases

AWS can be used for web applications, mobile applications, databases, backup and storage, data analytics, artificial intelligence, and enterprise applications.
