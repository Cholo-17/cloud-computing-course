# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is Google's cloud computing platform. It provides services for computing, storage, databases, networking, data analytics, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. This allows applications and services to operate across different geographic locations.

## Cloud Management Console

Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services

1. Compute Engine – Provides virtual machines.
2. Cloud Storage – Provides object storage.
3. Cloud SQL – Provides managed relational databases.
4. Google Kubernetes Engine (GKE) – Provides managed Kubernetes clusters.

## Three Advantages

1. GCP is strong in artificial intelligence and machine learning.
2. GCP provides strong Kubernetes and container support.
3. GCP has Google's global infrastructure and networking capabilities.

## Typical Enterprise Use Cases

GCP can be used for artificial intelligence, machine learning, big data analytics, Kubernetes applications, web applications, and large-scale data processing.
