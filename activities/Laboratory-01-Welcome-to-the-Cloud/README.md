# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I also created my Linux user account, explored the Linux environment, and prepared my Cloud Computing portfolio.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories.
- Create a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed Ubuntu through KillerCoda.
- Created a new Linux user.
- Logged in using the new account.
- Gathered system information.
- Created directories and Markdown files.
- Prepared a GitHub Cloud Computing portfolio.

## Skills Learned

I learned how to work with a Linux terminal, manage users, navigate directories, collect system information, create Markdown documentation, and organize a cloud computing portfolio.
