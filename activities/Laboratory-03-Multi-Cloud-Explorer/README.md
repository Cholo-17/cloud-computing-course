# Laboratory 03 – Multi-Cloud Explorer

## Linux Server Investigation

### Operating System

The Linux server is running the operating system identified using the `cat /etc/os-release` command.

### CPU Information

The CPU information was identified using the `lscpu` command.

### Memory

The memory information was identified using the `free -h` command.

### Disk Space

The disk space was identified using the `df -h` command.

## Cloud Services That Could Host the Linux Server

### AWS

The Linux server could be hosted using Amazon EC2. EC2 provides virtual machines that can run Linux operating systems.

### Microsoft Azure

The Linux server could be hosted using Azure Virtual Machines. Azure supports Linux virtual machines.

### Google Cloud Platform

The Linux server could be hosted using Compute Engine. Compute Engine provides virtual machines that can run Linux operating systems.
