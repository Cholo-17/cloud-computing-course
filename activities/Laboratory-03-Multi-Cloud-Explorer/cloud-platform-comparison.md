| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Virtual Private Cloud |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud Identity |
| Primary Strength | Broad range of services | Microsoft integration | AI, data, and Kubernetes |
| Ideal Organizations | Startups and enterprises | Microsoft-based enterprises | AI/data-focused organizations |

## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works especially well with products such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Google has extensive experience with AI and developed Kubernetes technology.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and supports many different types of applications. It would also provide opportunities to learn technologies that are widely used in cloud computing.
